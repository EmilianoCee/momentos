Current mirror

Feed a current into a transistor whose gate is tied to its drain, and it settles at the one V_GS that carries that current. Hand that V_GS to a second transistor and it carries the same current, scaled by how much wider it is. Drag its drain voltage and see how well the copy holds.

n = (W/L)₂/(W/L)₁ load

The mirror

The copy

= λ(V_out − V_GS)/(1 + λV_GS) in saturation

What should click

The diode connection sets V_GS. With gate tied to drain, M1 is always saturated and settles at the V_GS that carries I_REF: V_GS = V_T + √(2I_REF/k).

Same V_GS, same current per width. M2 sees the same V_GS, so it carries n times the current if it is n times as wide, as long as it is saturated and its drain sits where M1's does.

The copy costs λΔV. Channel-length modulation tilts M2's curve: each volt between the two drains adds about λ of error. A cascode is the cure.

Below V_OV it stops. M2 needs V_out ≥ V_OV to stay saturated. Below that it is a resistor, and the current falls.

A mirror is a big resistor without the drop. As a load it offers r_o to a signal while dropping only a few tenths of a volt of DC, so a common-source stage gains g_m r_o/2 instead of g_mR_D.

Predict, then try

  • With λ = 0.1 /V and V_out = 1.5 V, is I_out exactly 100 µA?
    whyNo, 106 µA, 6.4 % high. M2's drain sits 0.7 V above M1's, and with channel-length modulation each extra volt adds about λ of current.
  • Where should V_out sit for an exact copy?
    whyAt V_GS, 0.804 V: then both transistors have the same V_GS and the same V_DS, so they carry the same current per unit W/L.
  • Drag V_out below 0.3 V. What happens?
    whyM2 leaves saturation (V_out < V_OV = 0.304 V) and the current collapses toward zero: a mirror needs at least V_OV across its output.
  • Set n = 3. Does the error change?
    whyNo: the copy triples, but the percentage error depends only on λ and the drain-voltage difference.
  • In figure 3, switch between the loads, then change I_REF. Which gain moves?
    whyNeither. With R_D chosen to put the output at mid-supply, g_mR_D = V_DD/V_OV whatever the current; with the mirror, g_m r_o/2 = 1/(λV_OV). The mirror's gain is about four times higher because r_o is far larger than the resistor the supply allows.

Where this shows up

  • current mirror: the copy, its error λΔV and its lowest output voltage V_OV.
  • diode-connected transistor: M1, always saturated, setting V_GS for whatever it carries; 1/g_m to a small signal.
  • current-source load: the mirror in place of R_D, gain −g_m(r_o ∥ r_o).
  • channel-length modulation: the slope of the flat part, 1/r_o, which sets both the copy error and the load's resistance.
  • square law: V_GS from I_REF, and why the copy scales with W/L.
  • common source: the stage the mirror loads, compared with its resistor load.
